         Village in the Shade (PC Steam v1.30) - Thai Translation Mod
================================================================================

[ 1. ภาพรวมสถาปัตยกรรมของตัวม็อด (Plugin Architecture) ]
--------------------------------------------------------------------------------
• รูปแบบการโหลดปลั๊กอิน (Proxy DLL Hooking):
  - ใช้ไฟล์ "winmm.dll" วางข้าง "village.exe" ทำหน้าที่เป็น Windows Multimedia Proxy
  - เมื่อเกมเริ่มทำงาน winmm.dll จะสร้าง Background Worker Thread ขึ้นมาโหลด
    "Mods\TextDump\text_dump.dll" เข้าสู่แรมของเกมโดยอัตโนมัติ

• Zero Executable Modification (ปลอดภัย 100%):
  - ไม่มีการแก้ไขหรือดัดแปลงไฟล์ "village.exe" แท้ของ Steam แม้แต่ไบต์เดียว
  - โค้ดทั้งหมดจะทำการ Patch คำสั่งในหน่วยความจำ RAM ขณะรันเกมเท่านั้น
  - ตัวเกม Steam แท้จึงสะอาดบริสุทธิ์ ไม่มีความเสี่ยงเรื่องไฟล์เสียหายหรือติดปัญหา DRM

• การแยกไฟล์ตั้งค่า 2 ไฟล์อย่างชัดเจน (Clean Configuration Architecture):
  1. "settings.ini" (การตั้งค่าระบบเอนจิน):
     - วางไว้ที่โฟลเดอร์หลักของเกม (ข้าง village.exe)
     - บรรจุเฉพาะหมวด [Settings] สำหรับคุมการทำงานของฟังก์ชันใน DLL
     - มีสวิตช์เปิด/ปิดฟังก์ชัน เพื่อป้องกันม็อดพังเมื่อเกมมีการอัปเดตแพตช์ใหม่
  2. "cheats.ini" (ระบบสูตรโกงและปุ่มลัด):
     - วางไว้ที่โฟลเดอร์หลักของเกม (ข้าง village.exe) ที่เดียวเท่านั้น
     - บรรจุเฉพาะหมวด [Cheats] และ [Hotkeys]
     - มีระบบ Dynamic Hot-reload ตรวจสอบไฟล์ทุก 1 วินาที แก้แล้วเซฟมีผลทันทีไม่ต้องรีสตาร์ทเกม
     - หากไม่ต้องการใช้สูตรโกง สามารถเปลี่ยนชื่อเป็น _cheats.ini หรือลบทิ้งได้ทันที โดยไม่กระทบต่อระบบแปลภาษาไทย


[ 2. ระบบดักจับข้อความและแปลภาษา (Text Hooking & Translation Engine) ]
--------------------------------------------------------------------------------
• ฟังก์ชันของเอนจินเกมที่ทำการดักจับ (Hook Points ผ่าน MinHook):
  1. hk_putStr      : ฟังก์ชันวาดตัวอักษรและข้อความหลักของเกม
  2. hk_putStrProp  : ฟังก์ชันวาดตัวอักษรแบบจัดช่องไฟตามขนาดจริง (Proportional)
  3. hk_putStrAlign : ฟังก์ชันจัดหน้าข้อความ (ชิดซ้าย / กึ่งกลาง / ชิดขวา)
  4. hk_GetStringByID : ดักจับการดึงข้อความจากฐานข้อมูลตาม ID ข้อความ

• ดักจับภาษาอะไรบ้าง (Dual-Language Translation Support):
  - รองรับทั้ง "ภาษาญี่ปุ่น (JP)" และ "ภาษาอังกฤษ (EN)" พร้อมกัน 100%
  - ในไฟล์ "Mods\TextDump\translation.txt" สามารถใส่คำค้นหาต้นฉบับได้ทั้ง 2 ภาษา เช่น:
      こんにちは=สวัสดี          (ดักจับเมื่อเล่นโหมดญี่ปุ่น)
      Hello=สวัสดี             (ดักจับเมื่อเล่นโหมดอังกฤษ)
      木=ไม้                   (ดักจับเมื่อเล่นโหมดญี่ปุ่น)
      Wood=ไม้                 (ดักจับเมื่อเล่นโหมดอังกฤษ)
  - ไม่ว่าผู้เล่นจะเลือกเมนูเกมเป็นภาษาญี่ปุ่นหรืออังกฤษ ปลั๊กอินจะดักจับข้อความและสลับเป็นภาษาไทยให้ทันที

• ระบบแกะชื่อตัวละครและตัดสัญลักษณ์ (Dynamic Name & Bracket Stripper):
  - ปัญหาเดิม: เวลาผู้เล่นตั้งชื่อตัวละคร เกมจะนำชื่อไปต่อกับประโยคยืนยัน เช่น
    「สมศักดิ์」でよろしいですか？ หรือ Proceed with "Somsak"?
    ทำให้ในพจนานุกรมแปลไม่ได้เพราะชื่อของผู้เล่นแต่ละคนไม่เหมือนกัน
  - สิ่งที่ DLL ทำ:
    1. ตรวจจับและตัดสัญลักษณ์วงเล็บภาษาญี่ปุ่น 「 (0xE3 0x80 0x8C) และ 」 (0xE3 0x80 0x8D) พร้อมคำลงท้าย でよろしい
    2. ตรวจจับเครื่องหมายคำพูดภาษาอังกฤษ " พร้อมข้อความ Proceed with "..."?
    3. ดึงเฉพาะ "ชื่อที่ผู้เล่นตั้ง" ออกมาเก็บไว้ในตัวแปรชั่วคราว
    4. นำชื่อที่ได้ไปประกอบเข้ากับเทมเพลต: 「<value 1>」でよろしいですか？
    5. แปลงออกมาเป็นภาษาไทยบนหน้าจอว่า: "ต้องการใช้ชื่อ <value 1> ใช่หรือไม่?"

• ระบบแปลวันที่และฤดูกาลแบบไดนามิก (Date & Season Parser):
  - ดักจับแพตเทิร์นเวลาในแรม: <value 1>年目 <value 2> <value 3>日
  - ทำการแทนที่เลขปี, แปลงชื่อฤดู (春=ฤดูใบไม้ผลิ, 夏=ฤดูร้อน, 秋=ฤดูใบไม้ร่วง, 冬=ฤดูหนาว)
    และแปลงวันที่เป็นภาษาไทยให้โดยอัตโนมัติแบบเรียลไทม์


[ 3. ระบบฟอนต์ตัวชิดในแรม (Proportional Kerning In-Memory Patch) ]
--------------------------------------------------------------------------------
• ความเป็นมา:
  - ในโหมดภาษาญี่ปุ่น เอนจินเกมจะถูกบังคับให้เป็น Monospace (เว้นระยะห่างตารางคงที่เท่าขนาดคันจิ)
    ทำให้ตัวอักษรไทย สระ และวรรณยุกต์เว้นช่องไฟกว้างมากจนลอยและอ่านยาก
  - แต่ในโหมดภาษาอังกฤษ เกมจะใช้คำสั่ง putStrProp คำนวณความกว้างตัวอักษรตามจริง ทำให้ตัวหนังสือชิดสวยงาม
• สิ่งที่ DLL ทำ:
  - ทำการแพตช์ Branch คำสั่งเงื่อนไขใน RAM ตอนเปิดเกม 3 จุด (RVA: 0x0096AC62, 0x009ACA4E, 0x009ACC41)
  - บังคับให้เอนจินเกมรันคำสั่ง putStrProp ของภาษาอังกฤษมาใช้กับข้อความภาษาไทย
• ผลลัพธ์:
  - ตัวหนังสือชิดกันสวยงาม สระไม่ลอย อ่านง่ายสบายตา 100%
• สวิตช์ปิด/เปิด (Update-Proof):
  - ใน settings.ini หมวด [Settings] หัวข้อ: enable_proportional_font = 1
  - หากเกมอัปเดตแพตช์ใหม่ สามารถเปลี่ยนค่าเป็น 0 เพื่อปิดระบบนี้ได้ทันที


[ 4. ระบบแป้นพิมพ์ภาษาไทย 182 ปุ่มในเกม (Thai Virtual Keyboard Layout) ]
--------------------------------------------------------------------------------
• การทำงาน:
  - ดักจับตารางสตริงแป้นพิมพ์เสมือนใน RAM (RVA: 0x00E6E320 ถึง 0x00E6E750)
  - สลับตัวอักษรฮิรางานะและคาตาคานะของเกม ให้กลายเป็น "พยัญชนะไทย สระ วรรณยุกต์ และตัวเลขไทย รวม 182 ปุ่ม"
• ผลลัพธ์:
  - ผู้เล่นสามารถใช้เมาส์คลิกแป้นพิมพ์บนหน้าจอเพื่อพิมพ์ชื่อตัวละคร สัตว์เลี้ยง หรือข้อความภาษาไทยในเกมได้โดยตรง
• สวิตช์ปิด/เปิด (Update-Proof):
  - ใน settings.ini หมวด [Settings] หัวข้อ: enable_thai_keyboard = 1
  - หากเกมอัปเดตแพตช์ใหม่ สามารถเปลี่ยนค่าเป็น 0 เพื่อกลับไปใช้แป้นพิมพ์เดิมของเกมได้ทันที


[ 5. ระบบจำลองไฟล์เสมือน (Virtual File System - VFS Engine) ]
--------------------------------------------------------------------------------
• ฟังก์ชันของ Windows ที่ทำการดักจับ (Hook):
  - CreateFileW, CreateFileA, ReadFile, GetOverlappedResult (รองรับ Asynchronous I/O ของเกม ไม่ให้กระตุก)
• การแทนที่ไฟล์ภาพ (Textures & Minimap):
  - ดักจับไฟล์ภาพ UI และแผนที่จากโฟลเดอร์เกม แล้วสลับไปโหลดจากโฟลเดอร์ "Mods\TextDump\textures\<ชื่อไฟล์>.nltx"
  - ระบบสลับภาพอังกฤษ (English Texture Switch):
    หากเปิด "use_english_textures = 1" ใน settings.ini ตัว VFS จะสลับไปดึงภาพจากโฟลเดอร์
    "Mods\TextDump\textures_en\<ชื่อไฟล์>.nltx" ทันที (เช่น ผู้เล่นต้องการแผนที่เป็นภาษาอังกฤษ แม้จะเปิดเกมด้วยโหมดญี่ปุ่น)
  - สวิตช์ปิด/เปิด: enable_custom_textures = 1 ใน settings.ini
• การแทนที่ไฟล์ฐานข้อมูล (Dat Files):
  - ดักจับไฟล์ฐานข้อมูลเกมทั้ง 35 ไฟล์ แล้วสลับไปอ่านไฟล์แปลไทยจาก "Mods\TextDump\dat\<ชื่อไฟล์>.dat"
• การแทนที่ฟอนต์:
  - ดักจับและส่งมอบฟอนต์แท้ KiwiMaru-Regular.ttf และ KiwiMaru-Medium.ttf จาก "Mods\Fonts\"


[ 6. ระบบปรับความเร็วเกม (Speedhack Engine) ]
--------------------------------------------------------------------------------
• การทำงาน:
  - ใช้ MinHook ดักจับฟังก์ชันเวลาหลักของ Windows คือ QueryPerformanceCounter และ GetTickCount
    โดยตรงใน RAM (ระดับเดียวกับที่ Cheat Engine ทำ)
  - คำนวณตัวคูณเวลาแบบราบรื่น (Smooth Anchor Scaling) ทำให้เกมเร็วขึ้นหรือช้าลงทั้งระบบ
    (ทั้งการเดิน, แอนิเมชัน, เฟรมภาพ, การฟันดาบ, มอนสเตอร์) โดยไม่ต้องเปิด Cheat Engine
• ปุ่มลัดควบคุมความเร็ว (Hotkeys):
  - [ F4 ] : เร่งความเร็วเกม (Fast Forward) เป็น 2.0x (หรือตัวเลขที่ตั้งไว้ใน cheats.ini) พร้อมเสียงปี๊บเตือน
  - [ F5 ] : สโลว์โมชัน / เกมช้าลง (Slow Motion) เป็น 0.5x (หรือตัวเลขที่ตั้งไว้ใน cheats.ini) พร้อมเสียงปี๊บเตือน
  - [ F6 ] : คืนความเร็วเกมเป็นปกติ (Normal Speed 1.0x) พร้อมเสียงปี๊บเตือน
• สวิตช์ปิด/เปิด (Update-Proof):
  - ใน settings.ini หมวด [Settings] หัวข้อ: enable_speedhack = 1
  - หากปิดเป็น 0 ตัว DLL จะไม่ทำการฮุคระบบเวลาของ Windows เลยแม้แต่จุดเดียว 100%


[ 7. ระบบสูตรโกงและปุ่มลัดในเกม (Cheats & Hotkeys Engine) ]
--------------------------------------------------------------------------------
• เธรดปุ่มลัดความเร็วสูง (Dedicated Hotkey Thread):
  - มีเธรดวนลูปความถี่สูง (~40Hz / Sleep 25ms) ใช้พลังงาน CPU แทบเป็น 0% เพื่อดักฟังการกดปุ่มแบบ Real-Time
• ปุ่มลัดพิเศษ:
  1. [ F2 ] สลับ เปิด/ปิด หยุดเวลา (Freeze Time):
     - อิงตำแหน่งหน่วยความจำ Offset 0x3270 (ขนาด 8 ไบต์ int64) ตาม Cheat Table v1.30
     - กด F2 ครั้งแรก -> ล็อกเวลาไม่ให้เดิน พร้อมเสียงปี๊บเตือน (MB_OK)
     - กด F2 อีกครั้ง -> คืนค่าเวลาเดิม ให้เวลาเดินต่อตามปกติ พร้อมเสียงเตือน (MB_ICONASTERISK)
  2. [ F3 ] สลับ เปิด/ปิด เดินทะลุกำแพง (NoClip):
     - แพตช์คำสั่งการชน vitsNoClip ใน RAM กดปุ่มสลับเดินทะลุสิ่งกีดขวางได้ทันที
• ระบบ Infinite Stamina ปลอดภัย 100% (v1.30 Safe Refresh):
  - ตรวจสอบพอยน์เตอร์ใน RAM: 0x3A0 (Stamina ปัจจุบัน) และ 0x3AC (Stamina สูงสุด)
  - เติมพลังกายกลับมาเต็มเฉพาะเมื่อ Stamina ปัจจุบัน < Stamina สูงสุด ทุกๆ 100ms
  - ไม่แย่งเธรดเกมขณะเหวี่ยงเคียว/เกี่ยวข้าว แก้ปัญหาเกมเด้งหายขาด 100%
• รายการสูตรโกงที่เปิด/ปิดได้ใน cheats.ini [Cheats]:
  - god_mode              : อมตะ เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง
  - infinite_items        : ใช้ไอเทม/โยนของ/ปลูกผัก จำนวนไอเทมจะไม่ลดลง
  - infinite_stamina      : พลังกายเต็มหลอดตลอดเวลา
  - freeze_time           : หยุดเวลาในเกม (เวลาไม่เดิน)
  - infinite_money        : เงินไม่จำกัด (999,999)
  - noclip                : เดินทะลุกำแพง
  - no_materials_crafting : สร้างของ/คราฟต์ของ ฟรี (ไม่ต้องใช้วัตถุดิบ)
  - no_materials_cooking  : ทำอาหาร ฟรี (ไม่ต้องใช้วัตถุดิบ)
  - no_materials_smithing : ตีเหล็กและอัปเกรดเครื่องมือ ฟรี (ไม่ต้องใช้วัตถุดิบ)
  - no_materials_building : ก่อสร้างบ้านและโรงเลี้ยงสัตว์ ฟรี (ไม่ต้องใช้วัตถุดิบ)
  - no_materials_dyeing   : ย้อมสีเสื้อผ้าและเฟอร์นิเจอร์ ฟรี (ไม่ต้องใช้วัตถุดิบ)
  - submit_any_item       : ส่งเควสต์และบันเดิลด้วยไอเทมอะไรก็ได้


[ 8. สรุปสวิตช์ใน settings.ini สำหรับป้องกันเกมอัปเดต (Update-Proof Controls) ]
--------------------------------------------------------------------------------
ในไฟล์ settings.ini หมวด [Settings] ถูกสร้างขึ้นมาเพื่อความปลอดภัยสูงสุดเมื่อเกมอัปเดต:
• enable_proportional_font = 1 : หากเกมอัปเดตแล้วตำแหน่งคำสั่งตัวชิดเลื่อน สามารถปิดเป็น 0 ได้
• enable_thai_keyboard = 1    : หากเกมอัปเดตแล้วตารางแป้นพิมพ์เลื่อน สามารถปิดเป็น 0 ได้
• enable_custom_textures = 1  : เปิด/ปิด การใช้ภาพม็อด
• use_english_textures = 0    : สลับไปใช้ภาพ UI และแผนที่ภาษาอังกฤษ
• enable_speedhack = 1        : เปิด/ปิด ระบบฮุคความเร็วเกม (หากปิดเป็น 0 จะใช้เวลาเดิมของ Windows 100%)

หากวันใดที่ Steam มีการปล่อยอัปเดตแพตช์ใหม่ของเกม ผู้เล่นสามารถปิดฟังก์ชันเฉพาะจุดที่มีปัญหาใน settings.ini
แล้วเข้าเล่นเกมพร้อมตัวแปลภาษาไทยต่อได้ทันทีโดยไม่ต้องรอคอมไพล์ DLL ใหม่!
