[ 1. ภาพรวมสถาปัตยกรรมของปลั๊กอิน (System Architecture) ]
--------------------------------------------------------------------------------
• รูปแบบปลั๊กอิน: Proxy DLL Hooking
  - "winmm.dll" วางอยู่ข้าง village.exe ทำหน้าที่เป็น Windows Multimedia Proxy ดักจับ
    ตอนเกมเริ่มทำงาน แล้วสร้าง Background Worker Thread โหลด "Mods\TextDump\text_dump.dll"
  - รองรับ "village.exe ตัวแท้ดั้งเดิมของ Steam 100%" (Zero Executable Modification)
    ไม่ต้องแก้ไขไบนารีของไฟล์ exe บนดิสก์แม้แต่ไบต์เดียว ลดความเสี่ยงการโดนบล็อก และไม่กระทบตัวเกมแท้

• การแยกไฟล์ตั้งค่าอย่างชัดเจน (Clean Configuration Architecture):
  1. "settings.ini" (การตั้งค่าระบบม็อดและเอนจิน):
     - วางไว้ที่โฟลเดอร์เกม (ข้าง village.exe)
     - บรรจุเฉพาะหมวด [Settings] สำหรับคุมการทำงานของฟังก์ชันใน DLL
  2. "cheats.ini" (ระบบสูตรโกงและปุ่มลัด):
     - วางไว้ที่โฟลเดอร์หลักของเกม (ข้าง village.exe) ที่เดียวเท่านั้น!
     - บรรจุเฉพาะหมวด [Cheats] และ [Hotkeys]
     - มีระบบ Hot-reload ตรวจสอบการแก้ไขทุก 1 วินาที แก้แล้วเซฟมีผลทันทีไม่ต้องรีเกม
     - หากไม่ต้องการใช้สูตร สามารถลบหรือเปลี่ยนชื่อไฟล์ cheats.ini ได้ โดยไม่กระทบระบบแปลภาษา


[ 2. ระบบดักจับข้อความและแปลภาษา (Text Hooking & Translation Engine) ]
--------------------------------------------------------------------------------
• ฟังก์ชันที่ทำการดักจับ (Hook Points):
  1. hk_putStr      : ฟังก์ชันวาดข้อความหลักของเอนจิน
  2. hk_putStrProp  : ฟังก์ชันวาดข้อความแบบ Proportional (ตัวชิดตามขนาดจริง)
  3. hk_putStrAlign : ฟังก์ชันจัดหน้าข้อความ (ซ้าย/กึ่งกลาง/ขวา)

• รองรับ 2 ภาษาพร้อมกันใน translation.txt (Dual-Language Translation):
  - ใน "Mods\TextDump\translation.txt" สามารถใส่คีย์ต้นฉบับได้ทั้ง "ภาษาญี่ปุ่น" และ "ภาษาอังกฤษ"
  - เช่น:
      こんにちは=สวัสดี
      Hello=สวัสดี
      木=ไม้
      Wood=ไม้
  - เอนจินจะตรวจสอบข้อความที่ส่งมาวาด หากตรงกับภาษาใดภาษาหนึ่งในพจนานุกรม จะแทนที่ด้วยภาษาไทยทันที

• ระบบแกะสัญลักษณ์และการตั้งชื่อแบบไดนามิก (Dynamic Name & Bracket Stripper):
  - ปัญหาเดิม: เวลาตั้งชื่อตัวละคร เกมจะนำชื่อไปประกอบประโยคยืนยัน เช่น
    「สมศักดิ์」でよろしいですか？ หรือ Proceed with "Somsak"?
    ทำให้ในพจนานุกรมแปลไม่ได้เพราะชื่อเปลี่ยนไปตามที่ผู้เล่นตั้ง
  - โค้ดใน DLL แก้ไขโดย:
    1. ดักจับวงเล็บญี่ปุ่น 「 (0xE3 0x80 0x8C) และ 」 (0xE3 0x80 0x8D) พร้อมคำลงท้าย でよろしい
    2. ดักจับข้อความภาษาอังกฤษ Proceed with "..."? พร้อมเครื่องหมายคำพูด "
    3. ทำการตัดสัญลักษณ์วงเล็บและเครื่องหมายคำพูดออก ดึงเฉพาะ "ชื่อผู้เล่น" ออกมา
    4. นำชื่อที่ได้ไปแทนที่ลงในเทมเพลต: 「<value 1>」でよろしいですか？
       ซึ่งจะถูกแปลเป็น: "ต้องการใช้ชื่อ <value 1> ใช่หรือไม่?"
  - นอกจากนี้ยังมีระบบดักจับวันที่และฤดูกาลแบบไดนามิก:
    <value 1>年目 <value 2> <value 3>日 -> แทนที่ปี, ฤดู (春/夏/秋/冬) และวันที่เป็นภาษาไทยอัตโนมัติ


[ 3. ระบบฟอนต์ตัวชิดในแรม (Proportional Kerning In-Memory Patch) ]
--------------------------------------------------------------------------------
• ความเป็นมา:
  - ในโหมดภาษาญี่ปุ่น เอนจินของเกมจะถูกตั้งค่าเป็น Monospace (เว้นระยะคงที่เท่าคันจิ) ทำให้ฟอนต์ไทยห่างและสระลอย
  - ในขณะที่โหมดภาษาอังกฤษ เกมจะใช้ putStrProp คำนวณความกว้างตัวอักษรตามเนื้อจริง ทำให้ฟอนต์อังกฤษชิดสวยงาม
• การทำงานของ DLL:
  - ดักแก้ Branch คำสั่งใน RAM 3 จุดตอนเปิดเกม (RVA: 0x0096AC62, 0x009ACA4E, 0x009ACC41)
  - บังคับให้เอนจินเกมคำนวณข้อความภาษาไทยด้วยระบบ Proportional ของภาษาอังกฤษ
  - ผลลัพธ์: สระไม่ลอย ตัวหนังสือชิดกันสวยงาม อ่านง่าย สบายตา 100%
• การควบคุม:
  - เปิด/ปิด ได้ใน settings.ini ที่หมวด [Settings] หัวข้อ: enable_proportional_font = 1


[ 4. ระบบคีย์บอร์ดไทย 182 ปุ่มในเกม (Thai Virtual Keyboard Layout) ]
--------------------------------------------------------------------------------
• การทำงาน:
  - ดักจับตารางสตริงแป้นพิมพ์เสมือนใน RAM (RVA: 0x00E6E320 - 0x00E6E750)
  - สลับตัวอักษรฮิรางานะและคาตาคานะของเกม ให้กลายเป็น "พยัญชนะ สระ วรรณยุกต์ไทย และเลขไทย รวม 182 ปุ่ม"
  - ผู้เล่นสามารถใช้เมาส์คลิกพิมพ์ชื่อตัวละคร สัตว์เลี้ยง หรือข้อความภาษาไทยในเกมได้โดยตรง
• การควบคุม:
  - เปิด/ปิด ได้ใน settings.ini ที่หมวด [Settings] หัวข้อ: enable_thai_keyboard = 1


[ 5. ระบบจำลองไฟล์เสมือน (Virtual File System - VFS Engine) ]
--------------------------------------------------------------------------------
• ฟังก์ชันที่ทำการดักจับ:
  - CreateFileW, ReadFile, GetOverlappedResult (รองรับ Asynchronous I/O)
• การแทนที่ไฟล์:
  1. ภาพ UI / แผนที่ (Textures):
     - ปกติจะโหลดจาก: Mods\TextDump\textures\<ชื่อไฟล์>.nltx (ภาพภาษาไทย)
     - ระบบสลับภาพอังกฤษ (English Texture Switch):
       หากเปิด "use_english_textures = 1" ใน settings.ini ตัว VFS จะโหลดภาพจาก
       โฟลเดอร์ "Mods\TextDump\textures_en\<ชื่อไฟล์>.nltx" ทันที (เช่น แผนที่ภาษาอังกฤษ)
     - หากปิด "enable_custom_textures = 0" จะไม่โหลดภาพม็อด และใช้ภาพดั้งเดิมของเกม
  2. ฐานข้อมูลเกม (Dat Files):
     - ดักจับและแทนที่ไฟล์ database ทั้ง 35 ไฟล์จากโฟลเดอร์ Mods\TextDump\dat\<ชื่อไฟล์>.dat
  3. ฟอนต์พิเศษ:
     - ดักจับและส่งมอบฟอนต์แท้ KiwiMaru-Regular.ttf, KiwiMaru-Medium.ttf จาก Mods\Fonts\


[ 6. ระบบสูตรโกงและปุ่มลัดในเกม (Cheats & Hotkeys Engine) ]
--------------------------------------------------------------------------------
• เธรดปุ่มลัดความเร็วสูง (Dedicated Hotkey Thread):
  - ทำงานที่ความถี่ ~40Hz (Sleep 25ms) ใช้พลังงาน CPU แทบจะเป็น 0% แต่ตอบสนองต่อการกดปุ่มทันที
• ปุ่มลัดที่รองรับ:
  1. [ F2 ] สลับ เปิด/ปิด หยุดเวลา (Freeze Time):
     - อิงตำแหน่งหน่วยความจำ Offset 0x3270 (ขนาด 8 ไบต์ int64) ตามไฟล์ Cheat Table v1.30
     - กด F2 -> ล็อกเวลาไม่ให้ขยับ พร้อมเสียงปี๊บ Beep (MB_OK)
     - กด F2 อีกครั้ง -> คืนค่าเวลาเดิม ให้เวลาเดินต่อ พร้อมเสียงเตือน (MB_ICONASTERISK)
  2. [ F3 ] สลับ เปิด/ปิด เดินทะลุกำแพง (NoClip):
     - แพตช์คำสั่ง vitsNoClip ใน RAM กดปุ่มสลับได้ทันที

• ระบบ Infinite Stamina v1.30 ปลอดภัย 100%:
  - ปรับ Offset เป็น v1.30 ที่ถูกต้อง: Stamina = 0x3A0, Stamina Max = 0x3AC
  - ระบบ Safe Refresh: ตรวจสอบและเติมสตามินาเฉพาะเมื่อมีการใช้พลังงาน (Cur < Max)
  - ไม่แย่งเธรดเกมขณะเหวี่ยงเคียวเกี่ยวข้าว แก้ปัญหาเกมเด้งตอนเกี่ยวข้าวหายขาด 100%

• รายการสูตรโกงที่เปิด/ปิดได้ใน cheats.ini [Cheats]:
  - god_mode              : อมตะ เลือดไม่ลด ไม่โดนดาเมจ
  - infinite_items        : ใช้ไอเทม/โยนของ/ปลูกผัก ของไม่ลด
  - infinite_stamina      : พลังกายเต็มตลอดเวลา
  - freeze_time           : หยุดเวลาในเกม
  - infinite_money        : เงินไม่จำกัด (>= 999,999)
  - no_materials_crafting : คราฟต์ของฟรี
  - no_materials_cooking  : ทำอาหารฟรี
  - no_materials_smithing : ตีเหล็กฟรี
  - no_materials_building : ก่อสร้างฟรี
  - no_materials_dyeing   : ย้อมสีฟรี
  - submit_any_item       : ส่งเควสต์ด้วยไอเทมอะไรก็ได้
  - noclip                : เดินทะลุกำแพง


[ 7. ระบบสวิตช์ [Settings] ป้องกันม็อดพังเมื่อเกมอัปเดต (Update-Proof) ]
--------------------------------------------------------------------------------
ใน settings.ini หมวด [Settings] ถูกสร้างขึ้นมาเพื่อความปลอดภัยสูงสุด:
• enable_proportional_font = 1 : หากเกมอัปเดตแล้วตำแหน่งคำสั่งตัวชิดเลื่อน สามารถปิดเป็น 0 ได้
• enable_thai_keyboard = 1    : หากเกมอัปเดตแล้วตารางแป้นพิมพ์เลื่อน สามารถปิดเป็น 0 ได้
• enable_custom_textures = 1  : เปิด/ปิด การใช้ภาพม็อด
• use_english_textures = 0    : สลับไปใช้ภาพ UI และแผนที่ภาษาอังกฤษ

หากวันใดที่ Steam มีการปล่อยอัปเดตเวอร์ชันใหม่ของเกม ผู้เล่นสามารถปิดฟังก์ชันเฉพาะจุดที่มีปัญหา
ใน settings.ini แล้วเข้าเล่นเกมพร้อมตัวแปลภาษาไทยต่อได้ทันทีโดยไม่ต้องรอคอมไพล์ DLL ใหม่!
