[ 1. ขั้นตอนการติดตั้งม็อด (Installation) ]
--------------------------------------------------------------------------------
1. ไปที่โฟลเดอร์ติดตั้งเกมของ Steam:
   C:\Program Files (x86)\Steam\steamapps\common\Village in the Shade\
   (หรือคลิกขวาที่ชื่อเกมใน Steam -> จัดการ (Manage) -> เปิดดูไฟล์ภายในเครื่อง (Browse local files))

2. คัดลอกไฟล์ม็อดลงในโฟลเดอร์เกม:
   - นำไฟล์ "winmm.dll" และโฟลเดอร์ "Mods" 
   - วางลงในโฟลเดอร์เกมที่ระบุในข้อ 1
   (ใช้ไฟล์ village.exe ตัวแท้ดั้งเดิมของ Steam ได้เลย ไม่ต้องเปลี่ยนชื่อหรือแทนที่ไฟล์ .exe ใดๆ ทั้งสิ้น!)

3. เปิดเกมเล่นผ่าน Steam ได้ทันที!
   *หมายเหตุ: ในเกมให้เลือกตั้งค่าภาษาเป็น "ภาษาญี่ปุ่น" (ตัวเกมจะแสดงผลภาษาไทยทันที พร้อมฟอนต์ตัวชิดสวยงาม)*


[ 2. ระบบคีย์บอร์ดภาษาไทยในเกม (Thai Virtual Keyboard) ]
--------------------------------------------------------------------------------
• เมื่อถึงหน้าต่างตั้งชื่อตัวละคร, สุนัข หรือสัตว์เลี้ยง:
  - แป้นพิมพ์เสมือนในเกม (Virtual Keyboard) จะถูกเปลี่ยนเป็น "พยัญชนะ สระ และวรรณยุกต์ภาษาไทย 182 ปุ่ม" อัตโนมัติ
  - สามารถใช้เมาส์คลิกพิมพ์ชื่อภาษาไทย หรือชื่อสัตว์เลี้ยงได้โดยตรงทันที!


[ 3. วิธีเปิด/ปิด และตั้งค่าสูตรโกง (In-Game Cheats) ]
--------------------------------------------------------------------------------
* ไฟล์ตั้งค่าสูตรจะอยู่ที่: Mods\TextDump\cheats.ini *
(สามารถเปิดปรับแต่งสูตรได้ตลอดเวลา และอัปเดตผลทันทีขณะเล่นเกม)

• วิธีปรับแต่งสูตร:
  1. เข้าไปที่โฟลเดอร์: Mods\TextDump\
  2. เปิดไฟล์ "cheats.ini" ด้วยโปรแกรม Notepad
  3. แก้ไขตัวเลขหลังเครื่องหมาย = ของสูตรที่ต้องการ:
     - 1 = เปิดใช้งานสูตร (ON)
     - 0 = ปิดใช้งานสูตร (OFF)
  4. กดบันทึกไฟล์ (Save หรือ Ctrl+S)
     *ตัวเกมจะอัปเดตสูตรให้ทันทีภายใน 1 วินาที โดยไม่ต้องปิดเกมเปิดใหม่!*

--- รายการสูตรโกงที่สามารถเปิด/ปิดได้ [Cheats] ---
• god_mode = 1              : อมตะ เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง
• infinite_items = 1        : ไอเทมไม่ลด (ใช้ของ, โยนของ, ปลูกผัก จำนวนจะไม่ลดลง)
• no_materials_crafting = 1 : คราฟต์ของฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_cooking = 1  : ทำอาหารฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_smithing = 1 : ตีเหล็กและอัปเกรดเครื่องมือฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_building = 1 : ก่อสร้างบ้านและโรงเลี้ยงสัตว์ฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_dyeing = 1   : ย้อมสีเสื้อผ้าและเฟอร์นิเจอร์ฟรี ไม่ต้องใช้วัตถุดิบ
• submit_any_item = 1       : ส่งเควสต์และบันเดิลได้ทุกไอเทม (ใช้อะไรส่งก็ได้)
• infinite_stamina = 1      : พลังกาย (Stamina) เต็มหลอดตลอดเวลา ไม่เหนื่อย
• freeze_time = 0           : หยุดเวลาในเกม (1 = หยุดเวลา, 0 = เวลาเดินตามปกติ)
• infinite_money = 0        : เงินไม่จำกัด ล็อคเงิน 999,999 (1 = เปิด, 0 = ปิด)

--- ปุ่มลัดพิเศษขณะเล่นเกม [Hotkeys] ---
• [ F3 ] = สลับ เปิด/ปิด เดินทะลุกำแพง / สิ่งกีดขวาง (NoClip)
  - กด F3 ครั้งแรก = เปิดเดินทะลุ
  - กด F3 อีกครั้ง = คืนค่าเดินชนตามปกติ
  (สามารถเปลี่ยนปุ่มลัดได้ใน cheats.ini ที่หัวข้อ [Hotkeys])

* วิธีปิดสูตรทั้งหมดแบบทันที:
  - แค่เปลี่ยนชื่อไฟล์ "cheats.ini" เป็น "_cheats.ini" หรือลบออก เกมจะคืนค่าเดิมทันที 100%


[ 4. วิธีถอนการติดตั้งม็อด (Uninstall) ]
--------------------------------------------------------------------------------
1. เพียงแค่ลบไฟล์ "winmm.dll" และโฟลเดอร์ "Mods" ออกจากโฟลเดอร์เกม
2. ตัวเกมจะกลับคืนสู่สภาพเดิมของ Steam ทันที 100%!
