[ 1. ขั้นตอนการติดตั้งม็อด (Installation) ]
--------------------------------------------------------------------------------
1. ไปที่โฟลเดอร์ติดตั้งเกมของ Steam:
   C:\Program Files (x86)\Steam\steamapps\common\Village in the Shade\
   (หรือคลิกขวาที่ชื่อเกมใน Steam -> จัดการ (Manage) -> เปิดดูไฟล์ภายในเครื่อง (Browse local files))

2. คัดลอกไฟล์ม็อดลงในโฟลเดอร์เกม:
   - นำไฟล์ "winmm.dll", "cheats.ini" และโฟลเดอร์ "Mods" 
   - วางลงในโฟลเดอร์เกมที่ระบุในข้อ 1
   (ใช้ไฟล์ village.exe ตัวแท้ดั้งเดิมของ Steam ได้เลย ไม่ต้องเปลี่ยนชื่อหรือแทนที่ไฟล์ .exe ใดๆ ทั้งสิ้น!)

3. เปิดเกมเล่นผ่าน Steam ได้ทันที!
   *หมายเหตุ: ในเกมให้เลือกตั้งค่าภาษาเป็น "ภาษาญี่ปุ่น" (ตัวเกมจะแสดงผลภาษาไทยทันที พร้อมฟอนต์ตัวชิดสวยงาม)*


[ 2. ระบบการตั้งค่าป้องกันเกมอัปเดต [Settings] ]
--------------------------------------------------------------------------------
* ไฟล์ตั้งค่าจะอยู่ที่: cheats.ini (อยู่ข้าง village.exe ที่โฟลเดอร์หลักของเกม) *
• สามารถเปิดไฟล์ "cheats.ini" เพื่อเปิด/ปิดระบบการทำงานของม็อดได้อิสระ:
  - enable_proportional_font = 1 : ระบบฟอนต์ตัวชิดอัตโนมัติ (1 = เปิด, 0 = ปิด ใช้ฟอนต์เดิม)
  - enable_thai_keyboard = 1    : แป้นพิมพ์ภาษาไทย 182 ปุ่ม (1 = เปิด, 0 = ปิด ใช้แป้นพิมพ์เดิม)
  - enable_custom_textures = 1  : ระบบแสดงภาพ UI และแผนที่ภาษาไทย (1 = เปิด, 0 = ปิด)
  - use_english_textures = 0    : สลับไปใช้ภาพ UI และแผนที่ภาษาอังกฤษ (1 = ใช้ภาพอังกฤษ, 0 = ภาพไทย)
  *(หากในอนาคตเกมมีแพตช์อัปเดตใหม่แล้วมีส่วนไหนขยับ สามารถเปลี่ยนเป็น 0 เพื่อเข้าเล่นเกมต่อได้ทันที)*


[ 3. ระบบคีย์บอร์ดภาษาไทยในเกม (Thai Virtual Keyboard) ]
--------------------------------------------------------------------------------
• เมื่อถึงหน้าต่างตั้งชื่อตัวละคร, สุนัข หรือสัตว์เลี้ยง:
  - แป้นพิมพ์เสมือนในเกม (Virtual Keyboard) จะถูกเปลี่ยนเป็น "พยัญชนะ สระ และวรรณยุกต์ภาษาไทย 182 ปุ่ม" อัตโนมัติ
  - สามารถใช้เมาส์คลิกพิมพ์ชื่อภาษาไทย หรือชื่อสัตว์เลี้ยงได้โดยตรงทันที!


[ 4. วิธีเปิด/ปิด และตั้งค่าสูตรโกง (In-Game Cheats) ]
--------------------------------------------------------------------------------
• ปรับแต่งสูตรในไฟล์: cheats.ini
  - 1 = เปิดใช้งานสูตร (ON)
  - 0 = ปิดใช้งานสูตร (OFF)
  (ตัวเกมจะอัปเดตสูตรให้ทันทีภายใน 1 วินาที โดยไม่ต้องปิดเกมเปิดใหม่!)

--- รายการสูตรโกงที่สามารถเปิด/ปิดได้ [Cheats] ---
• god_mode = 0              : อมตะ เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง
• infinite_items = 0        : ไอเทมไม่ลด (ใช้ของ, โยนของ, ปลูกผัก จำนวนจะไม่ลดลง)
• infinite_stamina = 0      : พลังกาย (Stamina) เต็มหลอดตลอดเวลา ไม่เหนื่อย (ปลอดภัย 100%)
• freeze_time = 0           : หยุดเวลาในเกม (เวลาไม่เดิน)
• infinite_money = 0        : เงินไม่จำกัด ล็อคเงิน 999,999
• no_materials_crafting = 0 : คราฟต์ของฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_cooking = 0  : ทำอาหารฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_smithing = 0 : ตีเหล็กและอัปเกรดเครื่องมือฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_building = 0 : ก่อสร้างบ้านและโรงเลี้ยงสัตว์ฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_dyeing = 0   : ย้อมสีเสื้อผ้าและเฟอร์นิเจอร์ฟรี ไม่ต้องใช้วัตถุดิบ
• submit_any_item = 0       : ส่งเควสต์และบันเดิลได้ทุกไอเทม (ใช้อะไรส่งก็ได้)
• noclip = 0                : เดินทะลุกำแพง / สิ่งกีดขวาง (แนะนำใช้ปุ่ม F3)

--- ปุ่มลัดพิเศษขณะเล่นเกม [Hotkeys] ---
• [ F2 ] = สลับ เปิด/ปิด หยุดเวลาในเกม (Freeze Time)
  - กด F2 ครั้งแรก = หยุดเวลาทันที (มีเสียงปี๊บเตือน)
  - กด F2 อีกครั้ง = ปลดล็อก เวลาเดินต่อตามปกติ
• [ F3 ] = สลับ เปิด/ปิด เดินทะลุกำแพง / สิ่งกีดขวาง (NoClip)
  - กด F3 ครั้งแรก = เปิดเดินทะลุ
  - กด F3 อีกครั้ง = คืนค่าเดินชนตามปกติ


[ 5. วิธีถอนการติดตั้งม็อด (Uninstall) ]
--------------------------------------------------------------------------------
1. เพียงแค่ลบไฟล์ "winmm.dll", "cheats.ini" และโฟลเดอร์ "Mods" ออกจากโฟลเดอร์เกม
2. ตัวเกมจะกลับคืนสู่สภาพเดิมของ Steam ทันที 100%!
