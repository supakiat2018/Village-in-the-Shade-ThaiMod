  🌸 ม็อดภาษาไทย: Village in the Shade (v1.30 All-in-One ฉบับสมบูรณ์) 🌸
  [แปลไทยครบ 36 หมวดหมู่ + รองรับทั้ง EN/JP + คีย์บอร์ดไทย 182 ปุ่ม + สูตรโกง & Speedhack]
================================================================================

[ 1. ขั้นตอนการติดตั้งม็อด (Installation) ]
--------------------------------------------------------------------------------
1. ไปที่โฟลเดอร์ติดตั้งเกมของ Steam:
   C:\Program Files (x86)\Steam\steamapps\common\Village in the Shade\
   (หรือคลิกขวาที่ชื่อเกมใน Steam -> จัดการ (Manage) -> เปิดดูไฟล์ภายในเครื่อง (Browse local files))

2. คัดลอกไฟล์ม็อดลงในโฟลเดอร์เกม:
   - นำไฟล์ "winmm.dll" และโฟลเดอร์ "Mods" 
   - วางลงในโฟลเดอร์เกมหลัก (ข้างๆ village.exe)
   * หมายเหตุ: ไฟล์ตั้งค่าทั้งหมด (settings.ini และ cheats.ini) อยู่ในโฟลเดอร์ Mods\ เรียบร้อยแล้ว!
   * ใช้ไฟล์ village.exe ตัวแท้ดั้งเดิมของ Steam ได้เลย ไม่ต้องแก้ไขไฟล์ระบบใดๆ ทั้งสิ้น!

3. เปิดเกมเล่นผ่าน Steam ได้ทันที!
   * ตัวม็อดเวอร์ชัน v1.30 อัปเดตรองรับทั้ง 2 ภาษาหลักของตัวเกม:
     - ตั้งค่าภาษาในเกมเป็น "English" (อังกฤษ) : ม็อดจะดึงคำแปลภาษาไทยสำหรับโหมดอังกฤษ 100%
     - ตั้งค่าภาษาในเกมเป็น "Japanese" (ญี่ปุ่น) : ม็อดจะดึงคำแปลภาษาไทยสำหรับโหมดญี่ปุ่น 100%
     (พร้อมระบบจัดช่องไฟฟอนต์สระชิดสวยงาม และระบบรูปภาพ UI ภาษาไทยอัตโนมัติ)


[ 2. สวิตช์หลักเปิด/ปิด ม็อดภาษาไทย (Master Switch) ]
--------------------------------------------------------------------------------
* ตั้งค่าได้ที่ไฟล์: Mods\settings.ini (หัวข้อ [Settings]) *
• enable_thai_mod = 1 : [ค่าเริ่มต้น] เปิดใช้งานม็อดแปลภาษาไทยครบทุกระบบ
• enable_thai_mod = 0 : ปิดม็อดภาษาไทยทั้งหมด 100% 
  (ตัวเกมจะกลับเป็นภาษาอังกฤษ/ญี่ปุ่นดั้งเดิมของเกม แต่ "ระบบสูตรโกงและ Speedhack" ยังใช้งานได้เต็มระบบ!)
  * เหมาะสำหรับ: ผู้เล่นที่ต้องการเล่นเกมภาษาอังกฤษต้นฉบับ แต่อยากใช้สูตรโกง หรือเร่งความเร็วเกม! *


[ 3. การตั้งค่าระบบเอนจิ้นม็อดใน settings.ini ]
--------------------------------------------------------------------------------
• enable_proportional_font = 1 : ระบบจัดช่องไฟฟอนต์สระชิดอัตโนมัติ (1 = เปิด, 0 = ปิด)
  (สระและวรรณยุกต์ภาษาไทยจะเกาะติดพยัญชนะอย่างเป็นธรรมชาติ สวยงาม ไม่ลอย)

• enable_thai_keyboard = 1     : แป้นพิมพ์เสมือนภาษาไทย 182 ปุ่มในเกม (1 = เปิด, 0 = ปิด)
  (สำหรับคลิกพิมพ์ชื่อตัวละครและสัตว์เลี้ยงเป็นภาษาไทยในเกม)

• texture_mode = 1             : โหมดการแสดงผลรูปภาพ UI / เมนู / ใบปลิว (Smart 3-Mode)
  - 1 = [แนะนำ] ภาพที่แปลแล้วแสดงเป็น "ไทย" + ภาพที่เหลือดึง "อังกฤษ" มาแสดงแทน (ไม่มีหลุดเป็นญี่ปุ่น)
  - 2 = บังคับใช้ภาพ "ภาษาอังกฤษ" ทั้งหมด 100%
  - 0 = ปิดม็อดภาพ ใช้ภาพดั้งเดิมของเกม 100% (ไว้สำหรับป้องกันม็อดพังเมื่อเกมอัปเดตใหม่)

• enable_thai_minimap = 1      : ระบบภาพแผนที่ภาษาไทย (Thai Minimap)
  - 1 = [ปกติ] เปิดใช้งานแผนที่แปลภาษาไทย
  - 2 = ปิดเฉพาะแผนที่ภาษาไทย (สลับไปใช้แผนที่ภาษาอังกฤษจากตัวเกมแท้)
  - 0 = ปิดเฉพาะแผนที่ภาษาไทย (กลับไปใช้แผนที่ดั้งเดิมของเกม 100% โดยที่ภาพ UI อื่นๆ ยังเป็นภาษาไทยครบ)
  * คำแนะนำ: หากเปิดแผนที่ (กด M) แล้วเจอปัญหาจอสีเทาว่างเปล่า หรือเครื่องที่โหลดแผนที่ 4K ไม่ขึ้น ให้ปรับเป็น 2 หรือ 0 จะแก้ปัญหาได้ทันที!

• dat_en = 0                   : ระบบแทนที่ดาต้าเบสแปลจากอังกฤษ (1 = เปิด, 0 = ปิด)
• dat_ja = 0                   : ระบบแทนที่ดาต้าเบสแปลจากญี่ปุ่น (1 = เปิด, 0 = ปิด)
  * กลไกความปลอดภัยอัจฉริยะ (Smart Failsafe & Game Update-Proof):
    - ปิดทั้งสองตัวเป็น 0 [ค่าเริ่มต้นแนะนำ]: ระบบจะฮุคดึงคำแปลสดๆ ในแรมจาก translation.txt
      (ข้อดีสูงสุด: เมื่อ Steam มีอัปเดตแพตช์ใหม่ ตัวเกมจะไม่แครชหรือค้าง 100%)
    - หากเปิดเป็น 1: ระบบจะอ่านไฟล์ .dat จากโฟลเดอร์ Mods\TextDump\dat_en หรือ dat_ja
    - หากเผลอเปิด 1 ทั้งคู่: ระบบจะเลือกใช้ dat_en (EN) เสมอเพื่อป้องกันฐานข้อมูลขัดแย้งกัน

• enable_speedhack = 1         : ระบบปรับความเร็วเกม (1 = เปิดใช้งานปุ่มลัด F4/F5/F6, 0 = ปิด)


[ 4. ระบบแป้นพิมพ์ไทย และตรวจจับชื่อตัวละครอัตโนมัติ ]
--------------------------------------------------------------------------------
• แป้นพิมพ์ภาษาไทย 182 ปุ่มในเกม (Thai Virtual Keyboard):
  - เมื่อถึงหน้าต่างตั้งชื่อตัวละคร, สุนัข หรือสัตว์เลี้ยง แป้นพิมพ์ในเกมจะเปลี่ยนเป็นภาษาไทยอัตโนมัติ
  - ใช้เมาส์คลิกเลือกพยัญชนะ สระ และวรรณยุกต์ได้โดยตรง ไม่ต้องสลับหน้าต่างวินโดวส์

• ระบบตรวจจับชื่อตัวละครอัตโนมัติ (Dynamic Player Name Resolver):
  - ตัวม็อดมีระบบ AI วิเคราะห์ชื่อตัวละครที่คุณตั้งไว้ในเซฟเกมแบบ Real-time
  - นำชื่อตัวละครไปแทรกในบทสนทนาภาษาไทย (`<player>`) อัตโนมัติ โดยไม่ต้องแก้ไขไฟล์ใดๆ เพิ่มเติม!


[ 5. ระบบปรับความเร็วเกม (Speedhack Engine) ]
--------------------------------------------------------------------------------
• สามารถกดปุ่มลัดบนคีย์บอร์ดเพื่อเปลี่ยนความเร็วเกมได้ทันทีแบบ Real-time:
  - [ F4 ] : เร่งความเร็วเกม (Fast Forward สปีด x2.0 เท่า วิ่งไว ปลูกผักไว ทำงานไวขึ้น)
  - [ F5 ] : สโลว์โมชัน (Slow Motion สปีด x0.5 เท่า หลบมอนสเตอร์และสำรวจง่ายขึ้น)
  - [ F6 ] : คืนค่าความเร็วปกติ (Normal Speed x1.0 เท่า)
  *(สามารถปรับเปลี่ยนตัวคูณความเร็วได้อิสระในไฟล์ cheats.ini)*


[ 6. วิธีเปิด/ปิด และตั้งค่าสูตรโกง (In-Game Cheats) ]
--------------------------------------------------------------------------------
• ปรับแต่งสูตรโกงได้ที่ไฟล์: cheats.ini
  - 1 = เปิดใช้งานสูตร (ON)
  - 0 = ปิดใช้งานสูตร (OFF)
  (ตัวเกมจะอัปเดตค่าสูตรให้ทันทีภายใน 1 วินาที โดยไม่ต้องปิดเกมเปิดใหม่!)

--- รายการสูตรโกงที่สามารถเปิด/ปิดได้ [Cheats] ---
• god_mode = 0              : อมตะ เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง
• infinite_items = 0        : ไอเทมไม่ลด (ใช้ของ, โยนของ, ปลูกผัก จำนวนจะไม่ลดลง)
• infinite_stamina = 0      : พลังกาย (Stamina) เต็มหลอดตลอดเวลา ไม่เหนื่อย (ปลอดภัย 100%)
• freeze_time = 0           : หยุดเวลาในเกม (เวลาไม่เดิน) (สามารถกดปุ่มลัด F2 ได้)
• infinite_money = 0        : เงินไม่จำกัด ล็อกเงิน 999,999
• no_materials_crafting = 0 : คราฟต์ของฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_cooking = 0  : ทำอาหารฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_smithing = 0 : ตีเหล็กและอัปเกรดเครื่องมือฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_building = 0 : ก่อสร้างบ้านและโรงเลี้ยงสัตว์ฟรี ไม่ต้องใช้วัตถุดิบ
• no_materials_dyeing = 0   : ย้อมสีเสื้อผ้าและเฟอร์นิเจอร์ฟรี ไม่ต้องใช้วัตถุดิบ
• submit_any_item = 0       : ส่งเควสต์และบันเดิลได้ทุกไอเทม (ใช้อะไรส่งก็ได้)
• noclip = 0                : เดินทะลุกำแพง / สิ่งกีดขวาง (แนะนำใช้ปุ่มลัด F3)


[ 7. สรุปปุ่มลัดพิเศษขณะเล่นเกม [Hotkeys] ]
--------------------------------------------------------------------------------
• [ F2 ] : สลับ เปิด/ปิด หยุดเวลาในเกม (Freeze Time) - กดครั้งแรกหยุดเวลา / กดอีกครั้งเวลาเดินต่อ
• [ F3 ] : สลับ เปิด/ปิด เดินทะลุกำแพง (NoClip) - กดครั้งแรกเดินทะลุ / กดอีกครั้งเดินชนปกติ
• [ F4 ] : สปีดเกมเร็ว (Speedhack Fast 2.0x)
• [ F5 ] : สปีดเกมช้า (Speedhack Slow 0.5x)
• [ F6 ] : สปีดเกมปกติ (Speedhack Normal 1.0x)
*(สามารถเปลี่ยนปุ่มลัดได้อิสระในไฟล์ cheats.ini เช่น F1-F12, NUMPAD ฯลฯ)*


[ 8. วิธีรับมือเมื่อเกมอัปเดตแพตช์ใหม่ (Update-Proof Guide) ]
--------------------------------------------------------------------------------
• หากในอนาคต Steam มีอัปเดตแพตช์เกมใหม่:
  1. ตัวม็อดเชื่อมต่อผ่าน winmm.dll จึงไม่โดน Steam ลบหรือเขียนทับ
  2. หากเปิด `dat_en = 0` และ `dat_ja = 0` ไว้ตามค่าเริ่มต้น ตัวม็อดจะรันผ่าน Memory Hooking 100% ทำให้ปลอดภัยจากการแครชเมื่อตัวเกมหลักมีการเปลี่ยนแปลงไฟล์ .dat
  3. หากระบบภาพมีปัญหา ให้เปิด settings.ini แล้วปรับ "texture_mode = 0"
  4. หากระบบใดๆ มีปัญหา สามารถปิดเฉพาะระบบนั้นๆ เป็น 0 ได้ทันที โดยไม่ต้องลงเกมใหม่


[ 9. การแก้ปัญหาเกมเปิดไม่ติด / เด้งดับ (Troubleshooting) ]
--------------------------------------------------------------------------------
• หากเปิดเกมแล้วดับเงียบ หรือขึ้นแจ้งเตือนเกี่ยวกับ DLL:
  1. ปัญหาเกิดจาก Windows Defender / SmartScreen บล็อกไฟล์ DLL ที่ดาวน์โหลดจากอินเทอร์เน็ต
  2. วิธีแก้ไข: คลิกขวาที่ไฟล์ "winmm.dll" -> เลือก "Properties" (คุณสมบัติ)
     -> ดูที่ด้านล่างสุด หากมีข้อความความปลอดภัยและช่อง "Unblock" (ปลดบล็อก) ให้ติ๊กถูก -> กด "OK" (ตกลง)
  3. ทำแบบเดียวกันกับไฟล์ "Mods\TextDump\text_dump.dll"
  4. ตรวจสอบในไฟล์ "settings.ini" ว่า dat_en = 0 และ dat_ja = 0 (เป็นค่าปกติที่ปลอดภัยที่สุด)


[ 10. วิธีถอนการติดตั้งม็อด (Uninstall) ]
--------------------------------------------------------------------------------
1. ลบไฟล์ "winmm.dll", "settings.ini", "cheats.ini" และโฟลเดอร์ "Mods" ออกจากโฟลเดอร์เกม
2. ตัวเกมจะกลับคืนสู่สภาพเดิมของ Steam ทันที 100% สะอาด ไร้รอยต่อ!
