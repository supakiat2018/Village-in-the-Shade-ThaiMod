# 7. อัปเกรดระบบ DLL: Dynamic Template Matching สำหรับวันที่ในเซฟเกมและแพทเทิร์น <value>
# ------------------------------------------------------------------------------
# [ปัญหาเดิม]: ในหน้าเลือกเซฟเกม ช่องเซฟที่ 2 แสดงผลเป็นภาษาญี่ปุ่น "1年目 春 2日"
# เนื่องจากใน translation.txt มีการดักไว้เพียง "1年目 春 1日" และวันอื่นๆ ไม่กี่วัน เมื่อวันที่เปลี่ยนไปจึงกลายเป็นญี่ปุ่น
# [การแก้ไขผ่าน DLL]:
# - เพิ่มฟังก์ชัน try_match_dynamic_template ลงใน DLL (text_dump.c)
# - ตรวจจับและถอดรหัสวันที่แบบไดนามิก:
#   1) ถอดค่า ปี, ฤดู, วันที่ และช่วงเวลา (เช่น 深夜 = ยามดึก) จากข้อความภาษาญี่ปุ่น
#   2) ดึงแม่แบบจาก translation.txt อัตโนมัติ: <value 1>年目 <value 2> <value 3>日
#   3) แปลงชื่อฤดู (春, 夏, 秋, 冬) ผ่านคำแปลใน translation.txt แบบเรียลไทม์
#   4) ประกอบคำแปลภาษาไทยส่งให้เกมทันที (เช่น "ปีที่ 1 ฤดูใบไม้ผลิ วันที่ 2")
# - รองรับแม่แบบผันแปรอื่นๆ ครอบคลุมทั้งเกม:
#   - วันที่สั้นและวันเกิด/กำหนดส่ง: <value 1> <value 2>日, 誕生日 ..., 期限：...
#   - ตัวเลขและหน่วยนับ: <value 1>円, <value 1>個, 地下<value 1>階, 家畜小屋<value 1>, 鶏小屋<value 1>, <value 1>日後まで
#   - ฤดูกาลเก็บเกี่ยว: 収穫季節：<value 1>・<value 2>...
#   - ข้อความไอเทมและระบบ: 「<value 1>」を作成しますか？, <value 1>を手に入れた, <value 1>をもらった, <value 1>が足りない……, <value 1>を提出した, <value 1>との仲が深まった！, <value 1>のセーブデータを削除します。
# - Zero Hardcoded Thai: ในโค้ด DLL ไม่มีข้อความภาษาไทยฝังไว้แม้แต่คำเดียว ดึงจาก translation.txt ทั้งหมด 100%
# - ป้องกัน Buffer Collision ด้วยระบบ Ring Buffer 4 ชุด
