## 2. วิธีการหาตำแหน่งรูปภาพ (Methodology & Exact Formulas)

### ขั้นตอนที่ 1: โครงสร้าง Header ของ `resident_lang_jp.fad`
- ขนาดของ Header ส่วนหน้าสุด: **`0x4000` ไบต์ (16,384 ไบต์)**
- ตารางสารบัญ (TOC - Table of Contents) เริ่มต้นที่ Offset: **`0x1018`**
- แต่ละรายการใน TOC มีขนาดคงที่เท่ากันทุกรูป: **32 ไบต์ (`0x20` ไบต์)**

### ขั้นตอนที่ 2: โครงสร้างข้อมูลของ TOC แต่ละช่อง (32 Bytes Structure)
```c
struct FadTocEntry {
    uint64_t entry_size;    // [0x00] ขนาดรวมของบล็อกภาพ (Subheader + Desc + NLTX + Pad)
    uint32_t rel_offset;    // [0x08] ตำแหน่ง Byte Offset เริ่มต้น (นับจากหัว FAD)
    uint32_t unk1;          // [0x0C] ค่า Flag / รหัสประจำไฟล์
    uint32_t width;         // [0x10] ความกว้างของรูปภาพ (พิกเซล)
    uint32_t height;        // [0x14] ความสูงของรูปภาพ (พิกเซล)
    uint64_t unk2;          // [0x18] ค่า Padding / Descriptor สำรอง
}; // รวมขนาด = 32 ไบต์พอดี
```

### ขั้นตอนที่ 3: สูตรคำนวณตำแหน่งตายตัว 100% (Fixed Calculation Formulas)
1. **ตำแหน่งช่องสารบัญใน `resident_lang_jp.fad`:**
   $$\text{Offset in FAD} = 0x1018 + (\text{Index} \times 32)$$
2. **ตำแหน่งทางกายภาพในไฟล์ `fairy_1_00.dat` ทั้งก้อน:**
   $$\text{Offset in fairy\_1\_00.dat} = 0x425B9400 + 0x1018 + (\text{Index} \times 32)$$
   $$\text{Offset in fairy\_1\_00.dat} = 0x425BA418 + (\text{Index} \times 32)$$
3. **ความจุสูงสุดของตารางสารบัญใน Header:**
   $$\text{Max Entries} = \frac{0x4000 - 0x1018}{32} = \frac{12,264}{32} = 383 \text{ รายการ}$$
   *(Index ที่สามารถใส่ได้คือ Index 0 ถึง 382)*

## 3. แผนการ Repack แบบ Safe Append (เหมือนม็อดจีน ไม่เด้ง 100%)

1. **คงเนื้อหาเดิม 100% (Zero Shift):**
   - อ่านและคัดลอกเนื้อหาเดิมทั้ง `247,992,608 ไบต์` ของ `resident_lang_jp.fad` มาทั้งก้อน โดยไม่มีการตัดต่อ หรือเลื่อนตำแหน่งไฟล์เดิมแม้แต่ไบต์เดียว
2. **ต่อไฟล์ภาพใหม่ท้ายไฟล์ (Append to EOF):**
   - เริ่มต้นเขียนข้อมูลภาพภาษาไทยใหม่ที่ Offset ท้ายไฟล์: `0x0EC81120` เป็นต้นไป
   - โครงสร้างของข้อมูลภาพที่ต่อท้าย:
     - 32-byte Subheader
     - 32-byte Image Descriptor (กว้าง, สูง, Format Flag `0x0B010080`)
     - ข้อมูล NLTX แท้ของรูปภาษาไทย
     - Padding ให้หาร 16 ลงตัว
3. **อัปเดตสารบัญใน Header (0x1018):**
   - เขียนทับเฉพาะช่อง 32 ไบต์ของ Index นั้นๆ:
     - เปลี่ยน `rel_offset` ให้ชี้ไปที่ตำแหน่งต่อท้ายใหม่
     - เปลี่ยน `entry_size` ให้ตรงกับขนาดใหม่
     - อัปเดต `width` และ `height`
4. **เขียนประกอบกลับเข้า `fairy_1_00.dat`:**
   - นำ `resident_lang_jp.fad` ก้อนใหม่ที่ต่อท้ายแล้ว ใส่แทนที่ก้อนเดิม
   - อัปเดตขนาดในสารบัญของ `fairy_1_00.dat`
   - อาร์ไคฟ์อื่นๆ ทั้งหมดใน `fairy_1_00.dat` ยังคงเดิม 100%
