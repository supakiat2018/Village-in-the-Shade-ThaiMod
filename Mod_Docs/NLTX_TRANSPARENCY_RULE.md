# กฎเหล็กสำคัญ: ข้อห้ามเรื่องการแปลงไฟล์ NLTX และความโปร่งใส (Alpha Channel)

> [!CAUTION]
> **ข้อห้ามสำคัญสูงสุดสำหรับเกม Village in the Shade:**  
> **"ห้ามใช้การบีบอัดแบบ BC ผิดประเภทในการแปลงไฟล์ภาพ NLTX เด็ดขาด เพราะจะทำให้ค่า Alpha Channel (ความโปร่งใส) เพี้ยน ภาพใสแตก หรือแสดงภาพซ้อนทับฉาก"**

---

## 1. ทำไมถึงห้ามทำกับเกมนี้?

เกม **Village in the Shade** มีการใช้ภาพที่มีความโปร่งใส (Alpha Channel / Transparency) เป็นสัดส่วนที่เยอะมากในระบบ:
* ภาพแผนที่ย่อย (Minimaps)
* ไอคอนและมาร์กเกอร์จุดออนเซ็น (`minimap_onsen`)
* ป้ายและกรอบหน้าต่าง UI
* แถบแสดงผลสถานะและบทสนทนา

หากนำภาพเหล่านี้ไปแปลงเป็น NLTX ด้วยการบีบอัดแบบ **Block Compression (BC) ผิดประเภท** เช่น:
- นำภาพโปร่งใสไปบีบอัดด้วย **BC1 (DXT1)** ซึ่งรองรับความโปร่งใสแค่ 1-bit (ใสทะลุ 100% หรือทึบ 100% เท่านั้น ไม่มีระดับความโปร่งใส)
- หรือคำนวณ Premultiplied Alpha ผิดพลาด

**ผลกระทบที่เกิดขึ้นในเกม:**
1. ค่า Alpha Channel จะถูกทำลายหรือเพี้ยนไป
2. ขอบภาพจะดำ เป็นเม็ดพิกเซลแตก (ใสแตก)
3. ส่วนที่ควรจะโปร่งใสทะลุฉากหลัง กลับกลายเป็นสีทึบหรือแสดงภาพขึ้นมาทับฉากอื่น ทำให้ UI เละและอ่านไม่ออก

---

## 2. กรณีศึกษา: ปัญหาของภาพ `minimap_onsen`

### สาเหตุที่เกิดขึ้นในรอบก่อน:
* มีการใช้สคริปต์อัตโนมัติแปลงภาพออนเซ็นออกมาเป็นไฟล์ขนาด `16,411 ไบต์`
* การแปลงครั้งนั้นใช้ฟอร์แมตบีบอัด BC ผิดประเภท ทำให้เอนจินของเกมประมวลผลค่าความโปร่งใสไม่ได้
* ผลลัพธ์ในเกม: ภาพไอคอนออนเซ็นขึ้นมาแสดงทับแผนที่หลักอย่างไม่ถูกต้อง และมีรอยใสแตก

### การแก้ไขที่ถูกต้อง 100%:
* นำไฟล์ NLTX ต้นฉบับที่แท้จริงกลับมาใช้งาน (ขนาด **227 ไบต์** มี Header `NMPLTEX1` ดั้งเดิมของเอนจิน)
* ไฟล์ขนาด 227 ไบต์นี้เป็นบล็อกข้อมูลที่ตั้งค่าความโปร่งใสไว้ถูกต้องสมบูรณ์แบบ ไม่มีการแสดงผลทับซ้อนใดๆ ทั้งสิ้น

---

## 3. กฎปฏิบัติสำหรับการทำ Texture Mod ในอนาคต

1. **ภาพที่เป็น Overlay หรือมีส่วนโปร่งใส (เช่น ออนเซ็น, ไอคอน, มาร์กเกอร์):**
   - ห้ามนำไปรันสคริปต์ Re-encode บีบอัดใหม่เองแบบสุ่มสี่สุ่มห้า
   - หากต้องเปลี่ยนภาพ ต้องแน่ใจว่าใช้เครื่องมือที่รักษาโครงสร้าง Texture Descriptor และ Flag `0x0B010080` พร้อมค่า Alpha ครบถ้วน
2. **หากไฟล์เดิมเป็นภาพโปร่งใสที่ถูกต้องอยู่แล้ว:**
   - ให้ใช้ไฟล์เดิมนั้นต่อท้ายไฟล์ (Safe Append) เข้าไปตรงๆ โดยไม่ต้องแปลงใหม่
3. **การทดสอบความโปร่งใส:**
   - เมื่อเข้าเกม ต้องสังเกตขอบภาพว่าเรียบเนียน ไม่ติดขอบดำ และฉากหลังต้องทะลุผ่านได้อย่างเป็นธรรมชาติ
