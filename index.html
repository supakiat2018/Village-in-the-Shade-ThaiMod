Village in the Shade (ほの暮しの庭) — ม็อดภาษาไทยสมบูรณ์แบบ

สัมผัสบรรยากาศทำฟาร์มในสวนเงียบสงบแบบเต็มอรรถรสภาษาไทย พัฒนาด้วยเทคโนโลยี C In-Memory Text Hooking, Virtual File System (VFS) และฟอนต์ไทย PUA สระไม่ลอย คมชัด สบายตา

ดาวน์โหลดม็อด (Download Releases) ดูซอร์สโค้ดบน GitHub

สถานะโปรเจกต์ (Project Status)

ปัจจุบันม็อดนี้ ยังอยู่ในช่วงทดสอบ (เวอร์ชันเดโม่) จึงอาจยังมีคำศัพท์หรือบทสนทนาภาษาญี่ปุ่นบางคำหลุดโผล่อยู่บ้างในบางฉาก หากพบเจอคำใดที่ยังไม่แปล ตัวปลั๊กอินจะดักจับลงในไฟล์ dump_missing.txt ให้อัตโนมัติเพื่อนำมาอัปเดตคำแปลต่อในอนาคตครับ

ฟีเจอร์และจุดเด่นของม็อด

ออกแบบด้วยระบบที่เสถียรและทรงพลังที่สุด เพื่อประสบการณ์เล่นเกมที่ดีที่สุด

เกมอัปเดต ม็อดก็ไม่พัง

ใช้เทคโนโลยี Pattern Signature Scanning สแกนหาคำสั่งใน RAM แบบไดนามิก ไม่ดัดแปลงไฟล์เกมแท้ แม้เกมอัปเดตแพตช์ใหม่ ม็อดก็ยังทำงานร่วมกับเกมได้ตามปกติ

แปลไทยกว่า 47,950 บรรทัด

แปลครอบคลุมครบถ้วนทั้งบทสนทนาเนื้อเรื่อง, เควสต์, ป้ายร้านค้า, เมนูการตั้งค่า และไอเทมทั้งหมดในเกม

ฟอนต์ PUA สระไม่ลอย

ปรับแต่งระบบฟอนต์ PUA วรรณยุกต์ไม่ลอย ตัวอักษรคมชัด ไม่ซ้อนทับ อ่านง่าย สบายตาทุกความละเอียดหน้าจอ

ภาพ UI แปลไทย 70 ภาพ

รีทัชแปลภาพกราฟิกในเกมครบครัน ทั้งป้ายชื่อร้าน, ป้ายประกาศ, แผนที่, หน้าเมนูไตเติล และ UI หลักทั้งหมด

ป้อนชื่อไทยได้โดยตรง

พิมพ์ชื่อตัวละคร สุนัข และสัตว์เลี้ยงเป็นภาษาไทยได้ทันทีผ่านกล่องข้อความ หรือกดปุ่ม F2 พร้อมนำไปแสดงผลในบทสนทนาทุกจุด

สูตรโกงในตัว (Hot-Reload)

ระบบสูตรโกงอิสระในตัว ไม่ต้องใช้โปรแกรมเสริม ปรับแต่งผ่าน cheats.ini อัปเดตทันทีแบบเรียลไทม์

EASY INSTALLATION

วิธีติดตั้งสำหรับผู้เล่น

ติดตั้งง่ายมากใน 3 สเต็ป ไม่ต้องแก้ไฟล์แท้ของเกม

1

ดาวน์โหลดไฟล์ม็อด

ไปที่หน้าดาวน์โหลดและโหลดไฟล์ม็อดเวอร์ชันล่าสุด:

ไปที่หน้า Releases (ดาวน์โหลดที่นี่)
2

วางไฟล์ลงในโฟลเดอร์เกม

นำไฟล์ winmm.dll และโฟลเดอร์ Mods ไปวางไว้ในโฟลเดอร์เกม Steam:

C:\Program Files (x86)\Steam\steamapps\common\Village in the Shade\

*(ไม่ต้องเปลี่ยนชื่อไฟล์เดิมใดๆ ของเกมทั้งสิ้น วางคู่กันได้เลย)*

3

เปิดเข้าเล่นเกม

เปิดเข้าเกมผ่านแอป Steam ตามปกติ ตัวเกมจะเปลี่ยนเป็นภาษาไทยโดยอัตโนมัติทันที

วิธีถอนการติดตั้ง (Uninstall)

เพียงลบไฟล์ winmm.dll และโฟลเดอร์ Mods ออกจากโฟลเดอร์เกม ตัวเกมจะกลับคืนสู่ภาษาดั้งเดิม 100% โดยไม่มีผลกระทบต่อไฟล์เซฟ

✏️

วิธีใช้งานระบบป้อนชื่อภาษาไทย (Thai Name Input)

เมื่อถึงหน้าต่างตั้งชื่อตัวละคร, สุนัข หรือสัตว์เลี้ยงในฟาร์ม

ขั้นตอนที่ 1: เลือกตัวอักษรภาษาญี่ปุ่นในเกม 1 ตัว (เช่น あ หรือ ぎ) เพื่อปลดล็อคให้ปุ่ม "ยืนยัน" ในเกมเปิดทำงาน
ขั้นตอนที่ 2: คลิกปุ่ม "ป้อนชื่อไทย" ที่มุมซ้ายล่าง หรือกดปุ่มคีย์ลัด `F2` (สามารถกด Ctrl+V เพื่อวางข้อความได้)
ขั้นตอนที่ 3: พิมพ์ชื่อที่ต้องการในกล่องข้อความภาษาไทย จากนั้นคลิก "ตกลง (OK)"
ขั้นตอนที่ 4: คลิกปุ่ม "ยืนยัน" ในเกม ➡️ กล่องข้อความจะแสดงชื่อภาษาไทยของคุณ ➡️ เลือก "ใช่"

* ระบบจะบันทึกชื่อลงใน custom_names.ini และนำชื่อภาษาไทยนี้ไปแทนที่ในบทสนทนาทุกบท เมนู ป้ายชื่อ และหน้าสเตตัสอย่างแนบเนียน

⚡

ระบบสูตรโกงในตัวเกม (In-Game Cheats)

ปรับแต่งเปิด/ปิดสูตรผ่านไฟล์ cheats.ini ได้อย่างอิสระ

⚡ รองรับ Hot-Reload ไม่ต้องปิดเกม
ค่าใน cheats.ini คำอธิบายการทำงาน ค่าเริ่มต้น
god_mode = 1 อมตะ: เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง 1
infinite_items = 1 ไอเทมไม่ลด: ใช้งานไอเทม, โยนของ, วางของ, ปลูกผัก จำนวนไม่ลด 1
no_materials_crafting = 1 คราฟต์ของฟรี: สร้างสิ่งของได้ทันทีโดยไม่ต้องใช้วัตถุดิบ 1
no_materials_cooking = 1 ทำอาหารฟรี: ปรุงอาหารได้ทุกเมนูโดยไม่ต้องใช้วัตถุดิบ 1
no_materials_smithing = 1 ตีเหล็กฟรี: ตีเหล็กและอัปเกรดอุปกรณ์ได้ทันทีโดยไม่ต้องใช้วัตถุดิบ 1
infinite_stamina = 1 พลังกายไม่จำกัด: Stamina เต็มตลอดเวลา ทำงานได้ทั้งวันไม่เหนื่อย 1
freeze_time = 0 หยุดเวลาในเกม: ล็อคเวลาไม่ให้เดิน (1 = หยุดเวลา, 0 = เดินปกติ) 0
infinite_money = 1 เงินไม่จำกัด: ล็อคจำนวนเงินขั้นต่ำที่ 999,999 ตลอดเวลา 1

* หากต้องการปิดใช้งานสูตรทั้งหมดทันที เพียงเปลี่ยนชื่อไฟล์เป็น _cheats.ini ตัวเกมจะคืนค่าเดิมทั้งหมดทันที
