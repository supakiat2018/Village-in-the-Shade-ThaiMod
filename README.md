ม็อดแปลภาษาไทยสำหรับเกม **Village in the Shade (ほのぐらしの庭)** เวอร์ชัน PC Steam  
พัฒนาด้วยระบบ C In-Memory Text Hooking, Virtual File System (VFS) และระบบฟอนต์ภาษาไทย PUA สระไม่ลอย

> [!NOTE]
> ⚠️ **สถานะโปรเจกต์ (Project Status):**  
> ปัจจุบันม็อดนี้**ยังอยู่ในช่วงทดสอบ (เวอร์ชันเดโม่)** จึงอาจยังมีคำศัพท์หรือบทสนทนาภาษาญี่ปุ่นบางคำหลุดโผล่อยู่บ้างในบางฉาก หากพบเจอคำใดที่ยังไม่แปล ตัวปลั๊กอินจะดักจับลงใน `dump_missing.txt` ให้อัตโนมัติเพื่อนำมาอัปเดตคำแปลต่อในอนาคตครับ

## 🌟 ฟีเจอร์และจุดเด่นของม็อด (Key Features)

- 🛡️ **จุดเด่นสำคัญ — ต่อให้เกมอัปเดต ม็อดก็ยังใช้งานได้ (Update-Resistant):**  
  ม็อดถูกออกแบบด้วยเทคโนโลยี Pattern Signature Scanning สแกนหาคำสั่งในหน่วยความจำ RAM แบบไดนามิก และไม่ได้ดัดแปลงไฟล์ `.exe` หรือไฟล์ `.dat` แท้ของเกม ดังนั้น**แม้ในอนาคตตัวเกมจะมีการอัปเดตแพตช์ใหม่ ม็อดก็ยังคงทำงานร่วมกับเกมได้ตามปกติ**
- ✅ **แปลภาษาไทยสมบูรณ์:** ครอบคลุมบทสนทนา, เควสต์, ป้ายร้านค้า, เมนู และไอเทมกว่า **47,950 บรรทัด**
- ✅ **ระบบฟอนต์ PUA วรรณยุกต์ไม่ลอย:** ตัวอักษรคมชัด ไม่ซ้อนทับ อ่านง่าย สบายตา
- ✅ **ภาพอินเตอร์เฟซแปลไทย 70 ภาพ:** ป้ายร้าน, เมนู, แผนที่, ป้ายประกาศ และ UI หลักทั้งหมด
- ✅ **ระบบตรวจจับคำตกหล่นอัตโนมัติ (Missing Text Auto-Logger):** มีระบบ `dump_missing` คอยบันทึกเฉพาะคำภาษาญี่ปุ่นที่ยังไม่มีคำแปล ช่วยให้เก็บตกคำแปลได้แม่นยำ 100%
- ✏️ **ระบบป้อนชื่อภาษาไทย (Thai Name Input System):** รองรับการพิมพ์ชื่อตัวละคร สุนัข และสัตว์เลี้ยงเป็นภาษาไทยได้โดยตรงผ่านกล่องข้อความภาษาไทย หรือกดปุ่มคีย์ลัด F2 พร้อมระบบแทนที่ชื่อในบทสนทนาและเมนูทุกจุด
- ⚡ **ระบบสูตรโกงในตัวเกม (In-Memory Cheats System):** ปรับแต่งค่าสูตรผ่านไฟล์ `cheats.ini` รองรับ Hot-Reload ทันทีแบบเรียลไทม์ (อมตะ, ไอเทมไม่ลด, คราฟต์ฟรี, ตีเหล็กฟรี, ส่งของเควสต์ฟรี, วิ่งไม่เหนื่อย, หยุดเวลา, ล็อคเงิน 999,999)

## ✏️ วิธีใช้งานระบบป้อนชื่อภาษาไทย (Thai Name Input)

เมื่อถึงหน้าต่างตั้งชื่อตัวละคร, สุนัข หรือสัตว์เลี้ยงในฟาร์ม:
1. **เลือกตัวอักษรภาษาญี่ปุ่นในเกม 1 ตัว:** (เช่น `あ`, `ぎ` หรือตัวใดก็ได้) เพื่อปลดล็อคให้ปุ่ม "ยืนยัน" ในเกมเปิดทำงานตามระบบเกม
2. **เปิดกล่องป้อนชื่อภาษาไทย:**
   - คลิกที่ปุ่ม **"ป้อนชื่อไทย"** ที่มุมซ้ายล่างของหน้าจอตั้งชื่อ หรือ
   - กดปุ่มคีย์ลัด **`F2`** (หรือกด `Ctrl+V` เพื่อวางข้อความที่คัดลอกไว้)
3. **พิมพ์ชื่อที่ต้องการ:** ในกล่องข้อความภาษาไทย จากนั้นคลิก **"ตกลง (OK)"**
4. **กดยืนยันในเกม:** คลิกปุ่ม **"ยืนยัน"** ในเกม -> กล่องข้อความยืนยันจะแสดงชื่อภาษาไทยของคุณ -> เลือก **"ใช่"**
5. ระบบจะบันทึกชื่อลงใน `custom_names.ini` และนำชื่อภาษาไทยนี้ไปแทนที่ในบทสนทนาทุกบท เมนู ป้ายชื่อ และหน้าสเตตัสทั้งหมดของเกมอย่างแนบเนียน

## ⚡ ระบบสูตรโกงในตัวเกม (In-Game Cheats System)

ม็อดมาพร้อมกับระบบสูตรโกงในตัวที่พัฒนาด้วยเทคนิค Dynamic Memory Injection ไม่ต้องใช้ Cheat Engine หรือโปรแกรมภายนอก สามารถเปิด/ปิดสูตรได้อย่างอิสระผ่านไฟล์ `cheats.ini`

### 🔄 คุณสมบัติพิเศษ: Hot-Reload แบบเรียลไทม์
- แก้ไขค่าในไฟล์ `cheats.ini` แล้วกดบันทึก (Save) ตัวเกมจะอัปเดตสถานะสูตรทันทีใน 1 วินาที โดยไม่ต้องปิดเกมหรือโหลดเซฟใหม่
- **วิธีเปิด/ปิดสูตรทั้งหมดแบบทันที:**
  - **เปิดใช้งาน:** ตั้งชื่อไฟล์ว่า `cheats.ini` (วางไว้ในโฟลเดอร์เดียวกับ `text_dump.dll`)
  - **ปิดใช้งานทันที:** เพียงเปลี่ยนชื่อไฟล์เป็น `_cheats.ini` หรือลบไฟล์ออก เกมจะคืนค่าเดิมทั้งหมดทันที

### 📋 รายการสูตรที่รองรับ (`1` = เปิด, `0` = ปิด):
| ค่าใน cheats.ini | คำอธิบายการทำงาน |
| :--- | :--- |
| `god_mode = 1` | **อมตะ:** เลือดไม่ลด ไม่โดนดาเมจจากมอนสเตอร์และสิ่งกีดขวาง |
| `infinite_items = 1` | **ไอเทมไม่ลด:** ใช้งานไอเทม, โยนของ, วางของ, ปลูกผัก จำนวนจะไม่ลดลง |
| `no_materials_crafting = 1` | **คราฟต์ของฟรี:** สร้างสิ่งของได้ทันทีโดยไม่ต้องใช้วัตถุดิบ |
| `no_materials_cooking = 1` | **ทำอาหารฟรี:** ปรุงอาหารได้ทุกเมนูโดยไม่ต้องใช้วัตถุดิบ |
| `no_materials_smithing = 1` | **ตีเหล็ก/อัปเกรดอุปกรณ์ฟรี:** ตีเหล็กได้ทันทีโดยไม่ต้องใช้วัตถุดิบ |
| `no_materials_building = 1` | **ก่อสร้างสิ่งปลูกสร้างฟรี:** ก่อสร้างบ้านและโรงเลี้ยงสัตว์โดยไม่ต้องใช้วัตถุดิบ |
| `no_materials_dyeing = 1` | **ย้อมสีฟรี:** ย้อมสีเสื้อผ้าและเฟอร์นิเจอร์โดยไม่ต้องใช้วัตถุดิบ |
| `submit_any_item = 1` | **ส่งเควสต์/บันเดิลได้ทุกไอเทม:** สามารถนำไอเทมชิ้นใดก็ได้ไปส่งเควสต์ |
| `infinite_stamina = 1` | **พลังกายไม่จำกัด:** ค่า Stamina เต็มหลอดตลอดเวลา ทำงานได้ทั้งวันไม่เหนื่อย |
| `freeze_time = 0` | **หยุดเวลาในเกม:** ล็อคเวลาไม่ให้เดิน (`1` = หยุดเวลา, `0` = เวลาเดินปกติ) |
| `infinite_money = 1` | **เงินไม่จำกัด:** ล็อคจำนวนเงินขั้นต่ำที่ 999,999 ตลอดเวลา |

## 🎮 วิธีติดตั้งสำหรับผู้เล่น (How to Install)

1. ดาวน์โหลดไฟล์ม็อดจากหน้า [Releases](https://github.com/supakiat2018/Village-in-the-Shade-ThaiMod/releases)
2. นำไฟล์ `steam_api64.dll` และโฟลเดอร์ `Mods` ไปวางในโฟลเดอร์เกม:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Village in the Shade\
   ```
   *(อย่าลืมเปลี่ยนชื่อไฟล์ `steam_api64.dll` ตัวเดิมของเกมเป็น `steam_api64_org.dll` ก่อนวาง)*
3. เปิดเข้าเกมผ่าน Steam ตามปกติ ตัวเกมจะกลายเป็นภาษาไทยทันที

## 💻 วิธีการคอมไพล์จากซอร์สโค้ด (Build from Source)

เปิด Command Prompt หรือ PowerShell แล้วรัน:
```cmd
build.bat
```
หรือใช้คำสั่ง Zig CC:
```cmd
zig cc -shared -O2 -s src\text_dump.c src\addrsig.c src\cheats.c src\minhook-master\src\buffer.c src\minhook-master\src\hook.c src\minhook-master\src\trampoline.c src\minhook-master\src\hde\hde64.c -o bin\text_dump.dll -lkernel32 -luser32 -lgdi32
```
